# 上位机功能分工

[文档导航](README.md) · [项目架构](整个项目代码讲解.md) · [断点与排查](CodeSimplification.md)

主窗体创建一个共享 `AxisService`。手动页、控制权页、诊断页、造波页和四个固定轴对象围绕同一控制客户端工作。独立机器监控使用自己的只读连接，运行统计在需要时使用独立采样连接。

| 功能 | 从哪里进入 | 数据到哪里 |
| --- | --- | --- |
| 启动 ADS | [Mainpage](../Forms/main_page.cs) 的 `StartServicesAsync` | Router 就绪后分别启动监控和手动连接 |
| 手动轴反馈 | [AxisService.Feedback.cs](../Axis/Feedback/AxisService.Feedback.cs) 的 `ReadSnapshotAsync` | 一次 ADS 整帧读取，转换四轴快照并更新固定轴对象 |
| 机器监控 | [MachineMonitorService.cs](../Axis/Feedback/MachineMonitorService.cs) 的 `RefreshAsync` | 一次整帧读取，校验布局后处理时效和心跳，供页面显示 |
| 手动命令 | [AxisService.Manual.cs](../Axis/ManualControl/AxisService.Manual.cs) | 在现有锁和权限检查后写本站各轴命令字段 |
| 控制权 | [AxisService.Authority.cs](../Axis/ControlAuthority/AxisService.Authority.cs) | 写本站心跳、动作及序号，读取 PLC 同序号应答和授权 |
| 运行诊断 | [AxisService.Diagnostics.cs](../Axis/Feedback/AxisService.Diagnostics.cs) | 读取当前监控结构和四轴参数，显示故障来源及停车结果 |
| 下发点位 | [AxisService.PointUpload.cs](../Axis/PointUpload/AxisService.PointUpload.cs) | 从 PLC 读参，预检后分段发送，再等拼表就绪 |
| 轨迹会话 | [Axis/Trajectory](../Axis/Trajectory) | 捕获运行状态、取消、停稳确认和退出结果 |
| 运行采样 | [AxisRuntimeMonitoringService.cs](../Axis/Monitoring/AxisRuntimeMonitoringService.cs) | 记录实际位置、速度、质量与超限统计 |

## 需要保留的状态

- 控制连接是否可用直接查当前 ADS 客户端。`AxisService` 持有实际客户端，页面和读写入口查询同一个连接来源。
- 手动快照保留最后一次读取结果。机器监控的快照另外标记心跳、最近有效时间和字段质量，页面据此区分实时数据与不可用状态。
- 命令、控制权维护与部分轨迹读写串行。监控连接独立，避免页面轮询加入控制写入序列。
- 启动配置保存到运行目录，重启后由服务取得同一份配置。程序控制权以 PLC 读回为准。

PLC 符号、手动命令映射与监控布局查 [TwinCAT 对接](TwinCAT_NB_Integration.md) 和 [监控契约](PlcMonitoringContract.md)。点位、会话和实际采样分别查 [造波操作](WaveOperation.md) 与 [运行统计](AxisRuntimeMonitoring.md)。
