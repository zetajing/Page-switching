# 三站控制权与运行锁

[返回文档导航](README.md)

用户确认的优先级为：**造波控制室 > 拖车本地 > 远程操作室**。

2026-10-15 新增约束：**设备运行中禁止控制权交接，包括高优先级接管和当前站主动释放。** 高优先级申请不会为让权而强迫当前运行停车。运行中拒绝的请求立即应答，不排队到停机后自动执行；停稳后必须重新申请。

## 配套 PLC 协议

这是本次新增的配套协议，必须与 `PLC/TwinCAT_NB` 一起部署，不能直接套用到尚未升级的旧 PLC。

| 编码 | 本站身份设置 | 控制站 |
| --- | --- | --- |
| 0 | 空/未配置 | 未分配，不允许写轴命令 |
| 1 | WaveControlRoom | 造波控制室，最高优先级 |
| 2 | TowingLocal | 拖车本地 |
| 3 | RemoteControlRoom | 远程操作室 |

本站身份在启动时锁存，配置保存后重启生效。选择身份不等于取得 PLC 授权；每个站点身份应只运行一个命令客户端。

控制权采用纯软件申请，不依赖现场主控选择或授权开关。三个站均可提交申请，PLC 独立检查本站心跳、运行锁及优先级：

- 无持有者且设备未运行时，任一在线站可申请。
- 已有持有者且设备未运行时，只有更高优先级站可接管；本持有者重复申请确认现有权限。
- 运行中拒绝其他站接管和当前站释放；本持有者重复申请不改变控制权。
- 没有新申请不会自动选站；被拒绝的请求不排队，停稳后须重新申请。

旧版 `xCenterMaster`、`xLocalMaster`、`xAllowLocal`、`xAllowRemote` 已移除，不应再通过写入这些变量取得申请资格。上位机和 PLC 应配套更新；新版页面收到旧版结果码 3 时提示更新 PLC。

## 请求与应答

每站邮箱为 `GVL_control.aStation[1..3]`：

| 字段 | 写入端 | 语义 |
| --- | --- | --- |
| udiHeartbeat | 本站 | 每 250 ms 改变，PLC 3 秒不变判失联 |
| nAction | 本站 | 1 申请；2 释放 |
| udiRequestSequence | 本站 | 最后提交的新非零序号 |
| udiAckSequence | PLC | 已处理序号；拒绝也应答，不保留待接管请求 |
| nResult | PLC | 同序号结果，见下表 |
| xOnline / xGranted | PLC | 心跳有效 / 本站实际命令许可 |
| xWaveSession | 本站 | 发送、准备和执行会话锁，失联后忽略旧保持位 |
| aAxis[1..4] | 本站 | 四轴命令：使能、点动、回原、复位、停止和点动速度 |

| nResult | 含义 |
| --- | --- |
| 1 | 成功；本持有者重复申请只确认现有权限，不发生交接 |
| 2 | 运行或运动命令尚未退出，拒绝交接 |
| 3 | 保留：旧版现场授权拒绝，新版 PLC 不再返回 |
| 4 | 本站心跳未建立或已超时 |
| 5 | 非持有者不能释放 |
| 6 | 当前由更高优先级站持有 |
| 7 | 无效站点或操作 |

上位机先写动作，最后提交序号，等待相同序号应答和实际 Owner/Granted 确认。5 秒无确认提示结果不确定，不自动重试或显示授权成功。

## PLC 命令入口与运行锁

`FB_ControlAuthority` 维护私有 Owner；`GVL_control.nOwner` 只是反馈副本，直接改反馈不能取得权限。`FB_AxisCommandGate` 每扫描只把当前已授权邮箱命令复制到内部 `GVL_axis.Axis1..4`。原先多个站共写公共轴命令的接口不再使用。

交接扫描清空所有站点的旧运动命令，并阻断本扫描执行。新站必须在授权确认后重新发动作，不能继承另一站的使能、点动或回原请求。

运行锁覆盖：本站造波会话、轨迹校验/首点定位/执行/减速/退出、点动、回原、轴块 Busy、NC Moving/Homing/Stopping/外部给定、实际速度、无效 I/O，以及持有站已提交但尚未进入运动的点动/回原命令。只有轴和命令都退出后才允许交接。

失联时立即撤销命令许可、停止点动和轨迹并撤使能；运行中仍保留旧 Owner，其他站不能借失联接管。实际停车和命令退出后清 Owner。恢复心跳不自动恢复旧运动或旧权限，须重新申请并重新下发动作。

## 上位机页面

控制权页面保持原 Designer 结构，申请和释放按钮等待真实 PLC 应答。运行锁有效时两按钮禁用，PLC 仍独立检查运行锁，覆盖按钮点击后设备刚开始运行的窗口。反馈过期、身份未配置或未授权时，手动命令入口也拒绝动作。心跳不随手动页面隐藏停止。

监控地址 `GVL_HMI` 及类型保持兼容：前四项 UINT，心跳 UDINT；Owner 的显示文字与本次新三站协议统一。自动造波页面已接入上传、拼表、自动准备和启动/停止，协议详见 WaveOperation.md。

## 验证边界

`tests/verify_control_authority.py` 解析执行真实 `F_ControlDecision` 的 IF/赋值子集，检查运行中拒绝释放和所有跨站接管、三个站无主申请、停机优先级、离线及非法动作；另检查命令门控调用顺序。它不执行完整 PLC 状态机、TON 或 NC。

需在 XAE 编译并用仿真轴验证：保持点动/回原/轨迹时申请和释放均拒绝；松键且运动块退出后新申请才成功；失联先停车再清 Owner；交接后旧命令不重放。设备联锁和实机行为未在线验证。
