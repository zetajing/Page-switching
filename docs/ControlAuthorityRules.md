# 三站控制权切换规则

本说明整理用户于 2026-10-13 提供的规则，作为恢复控制权申请页面的开发依据。贵司或材料所方的正式书面说明、PLC 变量及现场联调结果仍需补充。

## 优先级与授权条件

**造波控制室操作 ＞ 拖车本地操作 ＞ 远程操作室操作。**

| 站点 | 生效条件 | 对其他站点的限制 |
| --- | --- | --- |
| 造波控制室 | 中心控制室处于主控模式 | 全局最高权限，仅中心控制室指令有效；自动锁定、屏蔽本地和远程全部操作权限 |
| 拖车本地 | 中心控制室解除主控，并开放本地操作授权 | 可开展检修、调试、局部试验；远程操作仍锁定 |
| 远程操作室 | 中心控制室和拖车本地均解除主控，并开启远程授权模式 | 任意高优先级站点介入主控，远程权限立即自动失效并锁定 |

解除主控不等于自动授权低优先级站点。申请发送成功不等于取得控制权，必须以 PLC 的实际授权反馈为准。按用户确认，三站优先级仲裁、授权、锁定和高优先级接管均由 PLC 负责；上位机只提交申请、释放请求并显示 PLC 反馈，不在本地切换控制权。

## 当前页面实现

- 主窗体“设备控制”区域恢复“控制权申请”，通过已有 `NavigateTo → ShowPage` 入口切换并缓存、释放页面。
- 布局与自动页、手动页统一，采用 `pagePanel` 最小画布、120 DPI 基准、统一标题及白色分组，操作按钮横向排列；滚动范围随 DPI 缩放后的最小画布同步。
- 页面采用普通 `partial UserControl` 及标准 Designer 结构，设计模式只初始化静态控件，运行时才应用监控快照。
- 页面展示上述规则，复用主窗体的只读监控快照，显示 ADS 连接、控制端、运行模式、反馈质量和 PLC 心跳；进入页面或点击“刷新状态”可请求刷新。
- 现有 `GVL_HMI.nControlOwner` 编码仍为 0 未分配、1 上位机、2 现场操作台、3 其他控制端；不能据此推定三站归属或优先级。
- 本站身份和三站授权反馈未定义，申请、释放按钮显示“待接入”并保持禁用；页面不创建写入客户端，也不发送控制权命令。原手动轴控制和自动造波范围保持原状，因此当前页面尚未实现设备端三站互锁。
- 页面切换、刷新操作及其提示通过现有操作日志记录。设备状态变化继续由自动页的快照日志统一记录。

## 接入前需要确认

1. 本机所属站点、三站 Owner 编码及其与现有反馈编码的关系。
2. 申请、释放、中心主控、本地主控、本地授权及远程授权的 PLC 符号、类型和语义。
3. 申请应答、拒绝原因、超时，以及释放后是否需要重新申请。
4. 高优先级接管、断线或心跳超时的 PLC 处理方式，包括现有运行命令的撤销与设备动作。

只读接口现状见 [PLC 监控接口](PlcMonitoringContract.md)。以上待确认项未获得定义前，不按猜测补充设备变量或模拟授权成功。
