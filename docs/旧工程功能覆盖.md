# 旧工程功能覆盖

按“自动造波先不动、PLC暂时只保留手动页面”实施。自动运行页保持原样；波形生成、分析、修正仅处理文件，不向PLC下发造波信号。现有手动轴命令时序和变量映射保持不变。

旧PLC的A/B反馈读取、标定系数写入、旧设备配置页面以及控制权占位页面已删除，待后续提供PLC资料再接入。水池和机械参数配置不再在项目中保存。

## 页面入口

| 功能 | 入口 | 说明 |
|---|---|---|
| 实测谱/理论谱对比与波浪要素 | 波浪分析 | 可打开当前会话CSV和旧采集TXT/DAT；数据管理也有“分析所选记录” |
| 实测波浪修正原造波信号 | 信号修正 | 调用旧WC-12.exe，显示新旧造波板位移对比，保留原文件 |
| 自定义波谱生成信号 | 波形生成→自定义谱 | 调用旧WP-7.exe，输入为有表头的频率/谱密度DAT |
| 原规则/不规则波计算程序 | 系统配置→旧WP-5-6.exe | 使用旧参数顺序和W3输出；流函数与椭圆余弦波使用此方案 |
| 多传感器共同水位标定 | 标定管理→批量标定 | 各通道独立原始值；全部计算成功后一次保存 |
| 旧传感器配置 | 标定管理→导入/导出CONF | 保留COM成对列和末行斜率/截距规则 |
| 旧采集文件输出 | 数据管理→导出旧TXT | 通道数/样本数/时间间隔、通道号、标定值；保持标定单位 |
| 波形计算程序目录 | 系统配置→波形程序目录 | 生成、分析和修正共用目录，不包含PLC或机械参数 |

新增静态控件位于Designer文件。页面操作和处理结果通过主窗体操作记录保存。

## 计算程序目录

在“系统配置→波形程序目录”选择旧工程的`bin/Debug`目录，点击“保存目录”。目录可单独保存，不要求配置WFast。规则/不规则波使用旧程序时，再选择“旧WP-5-6.exe”并点击“保存方案”。首次使用会尝试查找本机桌面上的已提供旧工程路径。目录通过`WaveProgramDirectory`保存到应用配置；EXE没有复制到仓库。

| 程序 | 已提供目录中的状态 | 接入方式 |
|---|---|---|
| WP-5-6.exe | 找到 | BasicParameters.dat：规则/不规则波 |
| WP-7.exe | 找到 | BasicParameters_user.dat：自定义谱 |
| WC-12.exe | 找到 | SigCorParamaters.dat：信号修正 |
| WaveTJU-6m-11.exe | 缺失 | SpecAnaParamaters.dat：旧分析程序，补齐后可选择此方案 |

旧程序每次在独立工作目录中运行，复制同目录DLL、CSV、DAT支持文件，传入CP936编码参数。等待进程结束、核对输出后才发布目标文件。错误会保留任务目录便于诊断。没有有效输出时不会显示计算成功，也不会覆盖原输入文件。

## 单位与算法

- 当前采集CSV的CalibratedValue按现有模型是mm，内置分析转换成m。未标定的原始计数不能作为波高分析。
- 旧采集文件没有单位字段，导入分析时明确选择mm或m。导入旧文件的会话也保留原单位，并按页面单位转换。会话和带同名.session.json的导出CSV使用记录的采样频率；没有会话信息的采集CSV使用页面指定频率，按样本顺序分析。TCP到达时间不作为均匀采样时钟。
- TimeSeconds/ElevationMetres文件是水面高程(m)。旧造波信号是带8行元信息的造波板位移(mm)，两者用途不同。
- 内置分析使用前面最大的2幂长度、去均值、Hann窗和单边FFT功率谱；光滑后保持离散谱总能量。统计采用上跨零波、波高排序，最高1/3、1/10和1/100的数量向上取整。
- 内置理论谱支持JONSWAP、P-M、B和ITTC，复用当前生成算法。水深记录在分析元信息中，内置谱没有浅水修正。规范、Scott、Darbyshire、Wallops使用旧分析EXE。
- 内置分析不宣称与缺失的旧EXE数值相同。旧程序输出和旧结果导入保留原单位；需要真实样例确认旧波高单位及谱密度单位。
- 分析DAT导出保留旧三列频谱和两组六项波浪要素结构；CSV是带要素名称的结构化输出，JSON记录计算来源和参数。
- 信号修正会将所选通道重新编号为单个测点1，保证测点列号和通道号不混用。传给旧程序的实测单位由页面选择，须与原工程使用单位一致。
- 二阶Stokes是当前内置算法选项；流函数和椭圆余弦波不会用Stokes冒充，需选择旧程序方案。

## PLC范围

PLC仅保留手动页使用的共享轴服务，以及它所需的ADS连接、Router和轴符号配置。主窗体显示该连接状态。未接入自动造波、旧反馈标定或控制权申请命令。

波形程序工作文件保存在`%LOCALAPPDATA%/PageSwitching/WavePrograms`，不再读取旧`equipment.json`。SQL Server继续只保存当前采集任务索引，不迁移旧MySQL表。
