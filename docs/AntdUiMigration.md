# AntdUI 全页面迁移

[返回文档导航](README.md)

## 当前范围

主窗体及 14 个页面（包括规则波、不规则波、自定义谱子页面）的按钮、文字、输入框、数值框、下拉选择、勾选/单选、日期选择、表格和标签页统一使用 AntdUI 2.4.12。系统使用统一浅色主题、圆角输入与按钮、分组标题和表头。

WinForms 的 Form、UserControl、TableLayoutPanel、FlowLayoutPanel 和必要的布局 Panel 继续承载布局；它们不是第二套交互界面。静态控件创建、尺寸和事件绑定继续位于 Designer。曲线统一使用 ScottPlot 5.1.59；原有四轴机械位置示意控件保留。

## 数据及行为

- 四轴反馈表为 AntdUI.Table，固定四行只读；无效反馈保留原始原因及颜色，超长文字可通过提示查看。
- 标定表直接绑定 DataTable，双击编辑，支持多行选择与删除。编辑完成先提交到绑定行，拟合和保存仍使用原流程。
- 数据管理的任务表和采样表直接绑定 DataTable；加载后明确刷新，再按任务 ID 恢复选择。任务对象不再存入旧 DataGridViewRow.Tag。
- AntdUI.Table 的 Columns 属性不由 VS Designer 序列化，因此列与数据绑定在明确的初始化方法中定义，表格控件的位置和尺寸仍可在 Designer 编辑。AxisFeedbackGrid 自身构造四轴列及占位行。
- 运行消息使用只读、多行 AntdUI.Input，最多保留 500 条，自动滚动并清除编辑撤销历史。
- 批量标定用六个 AntdUI.Checkbox 选择文件标定通道，默认只选择 CH1。浪高仪的 CH2–6 采集仍禁用，没有复制 CH1 数据。
- 对比曲线改用 ScottPlot，保留原始 X/Y、图例、单位、纵轴零基准及数组副本，提供复位视图与空状态。
- 导航、选中样式、结果日志及手动控制事件沿用原入口。自动清空、曲线工具栏和批量勾选不重复记录；后台程序设置下拉选项不冒充用户选择。
- 页面重复释放时只取消、释放一次任务对象，避免 Designer 重载报 CancellationTokenSource 已释放。

没有改动造波算法、机械换算、ADS 请求/句柄缓存、采集协议或 PLC 命令。

## 验证

- Debug、Release 构建零警告、零错误。
- 136 项离线检查：页面切换、控件挂载、快照/无效反馈、数值与单位、日志、CH2–6 限制、表格多选/删除/真实编辑提交、曲线单双系列与空状态、设计模式加载、重复释放和布局。
- 与迁移前代码对比全部 156 个已有输入默认属性，值保持一致。新增批量通道复选框另做检查。
- 对全部页面离线渲染并检查，配置页预览隐藏数据库连接和账号信息。预览使用占位或测试数据，不代表设备状态。
- 未连接 PLC、浪高仪或数据库，未调用旧造波/修正程序，没有做设备联机验收。
- DesignSurface 检查不替代实际 VS 的完整保存、关闭和重开验证；实际编辑时应使用新的构建结果打开源文件对应的设计器。
