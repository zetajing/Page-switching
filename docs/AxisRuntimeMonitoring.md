# 运行实测超限统计

[返回文档导航](README.md)

更新日期：2026-10-24。本功能在上位机独立读取和记录运行反馈，不修改 PLC 源码、结构布局、ADS 符号或运动参数，不增加停止动作。原有整表点位预检继续执行。

## 使用入口

1. 管理员登录，在“系统配置”底部打开“运行超限监测阈值”。每轴填写原始位置下限、上限和最大速度。下限须小于上限、速度须大于零，所有值必须有限。
2. 按原流程导入、发送、开始。开始时锁存一份阈值及版本，运行中保存的新配置仅下一场生效。
3. 造波页底部“运行实测超限占比”显示当前或最近一场报告，可滚动查看并复制。切换页面不会停止采样。

监测配置独立保存在 `%LOCALAPPDATA%/PageSwitching/AxisMonitoringSettings.json`，临时文件写完后再替换。操作员无保存权限；空白、损坏、缺少任一参数或版本不支持时不使用默认值，报告显示“未统计”及原因，仍允许原有造波流程。参数页为非模态窗口，主界面停止入口仍可操作。

这些阈值是分析标准，不是 PLC 限位或保护参数。当前读取 PLC/NC 原始位置和速度，不能直接标为造波板角度、电机转速或丝杆位移，相关机械换算仍待确认。实际角加速度、输出扭矩显示“未评估”，不使用设定值或零值冒充实测。

## 统计口径

仅接受本软件本次已上传轨迹序号、所属站匹配且 `Running=true` 的反馈。等待启动、使能回原、首点定位和退出阶段不计入百分比分母。序号或所属站改变时结束报告；正常退出、停止、故障及软件关闭保存结束原因。

| 项目 | 超限条件 | 有效分母 |
| --- | --- | --- |
| 每轴位置 | 位置 < 下限，或位置 > 上限 | 此轴位置有限且帧有效的样本数 |
| 每轴速度 | 速度绝对值 > 最大速度 | 此轴速度有限且帧有效的样本数 |
| 每轴任一项 | 同一时刻位置或速度超限 | 此轴位置、速度均有效的样本数 |
| 整体任一项 | 同一时刻四轴任一已接入项超限 | 四轴位置和速度全部有效的完整样本数 |

每项比例 = 超限有效样本数 ÷ 该项有效样本数 × 100%。等于阈值边界不计超限。多轴或多项同时超限时，每轴和整体各自按采样时刻只计一次，不能把各项百分比相加。某轴一个数值无效时，其他有效单项仍可计数，但该轴合计和整体完整样本不计数。

例如：100 个完整样本中，轴1位置超限8次、速度超限5次，其中重叠3次，轴1任一项为 `(8+5-3)/100=10%`。整体须继续对四轴求并集。显示最多六位小数，并保留分子/分母；零有效样本显示“未取得有效样本（0/0）”，不显示0%合格。

读取失败、重复 PLC 心跳、NC 反馈无效、NaN/Infinity、过期采样机会分别计数并标记统计不完整；连接中途恢复不会消除之前的缺测。短轨迹完全没采到正式执行帧时，也显示未取得有效样本和范围不完整。首次观察已明显晚于执行开始时标记不完整，不能声称无缺测；窗口采样本身始终不能证明连续全时历覆盖。

读取失败、重复和跳过次数是采样任务的诊断计数，包含等待执行期间的尝试，不混入超限分母；NC无效和非有限数值计数针对本次执行帧。一次读取有多种无效原因时按过滤顺序归类，CSV仍保留收到的运行标志、NC有效性及数值标记。

本功能表示**实测瞬时采样点的超限占比**，不是连续时间超限比例，不能保证捕获100 ms间隔内的短峰，也不代替“限制/修正生成运动时历并计算受限部分”的功能。

## 采样与文件

`AxisRuntimeMonitoringService` 持有唯一一份本次计数，页面只显示快照。独立 `AdsAxisMonitoringSource` 复用原连接目标及 InduLink，只有读取能力，不使用运动命令锁，不写心跳或控制权，也不使用主界面500 ms缓存。

- 读取 `GVL_HMI.stMonitor` 并校验现有布局，再核对 `GVL_control.xFeedbackInvalid`。这两次 ADS 读取不是原子事务；时间戳明确为上位机读取完成时刻。
- 单调时钟安排目标100 ms节拍，每次只读一帧；落后后跳过过期机会，既不补读缓存也不突发追赶。
- 连接超时1秒，连接后的整次读取取消期限500 ms。失败后等待1秒重试。实际节拍受网络和操作系统调度影响。
- 正常操作结束时不等待采样，最多给下一次独立读取600 ms观察窗口；软件关闭立即取消，并最多等待统计清理2秒。不能确认的末段仍标记不完整。
- 只记录“进入超限、恢复、读取错误变化/恢复、结束汇总”，不按100 ms刷操作日志。采样或文件失败不覆盖运动故障或停车确认。

每场目录：`%LOCALAPPDATA%/PageSwitching/AxisMonitoring/yyyyMMdd-HHmmss-运行GUID/`。

| 文件 | 内容 |
| --- | --- |
| `samples.csv` | 每次尝试的读取完成时间、耗时、PLC心跳、轨迹序号、所属站、运行及NC有效性、结果原因、四轴原始位置和速度；非统计阶段及无效帧也保留原因，NaN/Infinity保留文本方便定位，读取失败时反馈字段留空 |
| `summary.json` | 轨迹和站、阈值快照/版本、起止时间、首末有效样本时间、各项分子分母、缺测/重复计数、结束原因、完整性及保存错误 |

CSV 逐行流式写入，不在内存积累整场采样；只有固定四轴计数和当前帧。开始先保存阈值快照及进行中摘要，结束后用临时文件原子替换汇总。软件被强制终止时可能有未刷新的CSV尾部；进行中摘要不能当作已完成报告。文件失败只影响统计，内存计数可继续，页面明确提示记录不完整。

`samples.csv` 使用带 BOM 的 UTF-8 编码，便于 Excel 直接识别中文 `Outcome`。旧版生成的不带 BOM 文件可在 Excel 的“数据 → 从文本/CSV”中按 UTF-8（65001）导入；若已经按错误编码打开，不要覆盖原文件后再转换。

监测配置现在是 `panel/AxisMonitoringSettingsPage`，从系统配置进入、返回系统配置；页面由主窗体缓存并统一释放，保留独立 Designer 文件。运行诊断使用 `panel/MachineDiagnosticsPage`，从主界面左侧“系统 → 运行诊断”进入，返回自动运行页。两个入口均不创建独立 Form，诊断导航向管理员和操作员开放。
