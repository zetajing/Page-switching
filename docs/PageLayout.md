# 页面布局与验证

更新日期：2026-10-29。布局检查包含主导航、自动、手动、控制权、诊断、监测阈值、数据管理、数据库记录、系统配置和浪高监测，保持原有命令、权限、数据读取与保存流程。

- 主导航统一左边距、宽度、字体和行距；设备控制、数据工具、系统仍按原分组排列。滚动范围由内容计算，小窗口不会因固定大画布出现多余滚动条。
- 自动页右侧移除反馈与消息之间的空白占位行；反馈保留原高度，消息区紧跟下方并填满剩余空间。清空按钮底行保留足够高度和边距。
- 手动页压缩标题、全轴按钮区的留白，略收窄右侧标签列，为输入和数值留出空间。四轴映射、显示范围、按钮事件和单位隐藏方式保持原样。
- 控制权页为操作按钮增加行空间，保留用户已修改的按钮尺寸；滚动画布由已有最小尺寸和布局逻辑管理。此次未覆盖用户原有的字体、DPI、尺寸等调整。
- 运行诊断新增页面标题，使用统一圆角按钮、浅色表头和白色正文区域；四轴参数表保持紧凑，主要空间用于诊断内容。
- 监测阈值页新增标题，四轴表格使用固定高度，保存和返回按钮紧跟配置与状态说明。管理员保存、操作员只读、下次运行生效的逻辑保持不变。
- 数据管理的日期、通道和查询放在筛选行，导入、导出、分析和数据库入口放在操作行；两行直接放入根布局，避免嵌套自动布局挤走明细和波形。任务表与样本表的列填满表格宽度。
- 数据库记录使用两行固定筛选：第一行选择类型、时间并查询，第二行填写任务编号；同步、导出和返回另起操作行。主按钮为蓝色，次按钮有边框，空表给出提示，底部结果按文字高度展开。
- 系统配置只保留内部内容面板滚动，去掉外层重复的最小画布；窄窗口仍可滚动到数据库连接、账号和建表按钮。

所有可见布局继续保存在各页 `.Designer.cs` 中。设计尺寸会跟随 DPI 缩放，不需要在代码中再次乘缩放比例。自动页只应用上述右侧布局改动，其余本地布局、配置和资源改动保留在工作区。
