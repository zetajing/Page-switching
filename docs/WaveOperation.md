# 造波页操作与通信

[返回文档导航](README.md)

本功能只执行已确认的最终 PLC 轴点位，不生成、缩放或换算波形，不启用主动吸收。导入一套点位后，四轴使用完全相同的位置表，周期固定为 2 ms。

## 四个按钮

1. 导入造波信号：选择旧格式 CSV/TXT/DAT，首行为表头，其后为 8 行元信息，再后为声明数量的位置行。点数 4～2,100,000，周期必须为 0.002 秒，第一列必须为有限数值。第二列忽略，水面高程文件拒绝。失败保留上一次文件。
2. 发送造波信号：本站先取得控制权，确认轴已停稳、基础块空闲且 NC 反馈有效；允许轴处于未使能 Disabled 状态，无需先使能或回原。页面显示未满足的发送条件。服务清旧接收状态，采用新的非零轨迹序号，向四轴逐段下发；每段四轴全部写完才登记并等 PLC 确认。全部下发后单独请求拼表，确认 DataReady 和累计点数、序号、所属站一致才显示已发送。不会自动运动。
3. 开始造波：要求本文件已发送，PLC 联锁、参数及反馈有效，无轴报警。按钮不可用时，详情区逐项列出“暂不能开始”的原因。自动清旧点动/回原/停止请求、保持四轴使能；10 秒内等使能成功，仅对未回原的轴发回原请求，120 秒内等四轴回原且运动块退出；然后请求现有轨迹块进行整表校验、首点定位和执行。NC 回原方式、速度、原点传感器仍由现场配置提供。
4. 停止造波：取消本服务正在发送或准备的任务，禁止迟到写入继续启动。PLC 取消收段/拼表/校验或从当前位置减速退出；回原由基础块停止。先等实际停稳，再释放停止位、等 MC_Stop 退出，最后显示已停止。正常人工停止不报通用 1007 故障，真实轴故障和联锁仍保持故障。

发送、准备、执行期间禁止更换文件、重复启动和手动操作，停止入口独立可用。本站没有有效控制权时只能本地导入和读取反馈。自然完成或停止后，下次运行必须重新发送；不循环、不重放旧序号、不自动重试运动命令。页面切换不停止已运行轨迹；程序退出先取消并尝试停车，再释放服务。

## 虚拟轴调试参数

四轴参数统一在 `GVL_motion.aConfig[1..4]` 中初始化，手动控制、监控和轨迹读取同一份配置。不要在 `FB_AxisControl` 内给 `Config` 赋固定值：它是输入副本，不会更新全局数组，可能造成手动可运行、监控却判定配置无效。

当前四轴使用以下虚拟轴调试初值，数值单位跟随 NC；它们不是已确认的实机参数：

| 参数 | 初值 |
| --- | ---: |
| 最小位置 / 最大位置 | -200 / 200 |
| 最大速度 | 100 |
| 最大加速度 | 100 |
| 停车减速度 | 100 |
| 首点定位速度 `lrInitVelocity` | 10 |
| 到位容差 `lrStartTolerance` | 10 |

源码默认值不会直接改动在线 PLC。在线更改可能保留已有变量值，快速在线更改也不生成初始化代码；更新 PLC 后需核对四轴全局参数的实际值，不能只检查功能块内部的值。[Beckhoff 在线更改说明](https://infosys.beckhoff.com/content/1033/tc3_plc_intro/2528041355.html)

重新启动上位机后，本地上传资格不会恢复；需要重新申请有效控制权、导入并发送点位，等 PLC 拼接完成再开始。开始前显示“手动”模式是正常状态，模式反馈不是启动的前置条件。

## 数据和权限

- 反馈地址只有 AdsMonitorSnapshot=GVL_HMI.stMonitor，版本 3 / 148 字节；手动页、机器监控和造波服务复用同一结构定义。
- ST_ControlStation 增加 xWaveSession，会话期间阻止接管/释放；站点失联后撤命令停车，实际运动锁仍独立有效。
- GVL_motion.nCommandStation 是命令来源号，必须匹配当前有效 Owner。PLC 锁存 nUploadStation，控制端变化或失联使旧表失去启动资格。它属于应用协议，不代替 ADS 访问权限。
- GVL_motion.aUpload 仍是 21 段 × 4 轴 × 每轴 100000 点；以小批次最多 1024 点通过 DLL WriteManyAsync 写标量符号。DLL 的 WriteArrayAsync 只能写尺寸匹配的完整数组，不能把某个 LREAL 符号当作数组切片。
- 每批释放共享 ADS 门锁，停止和心跳可穿插。发送遇到任何写入或确认失败立即中止，不把部分成功当成完整接收。
- 本站心跳约 250 ms 更新；造波会话期间同时更新轨迹心跳；PLC 自己约 500 ms 更新反馈心跳。造波服务检查反馈心跳变化，停止不确定时暂停本站心跳，让 PLC 独立失联停车；确认停稳后重启上位机恢复，不自动重连续跑。
- 明确重发时可单次清组故障后重新清表，不反复复位，也不自动复位各轴报警。

## 监控布局扩展

前 104 字节的四轴反馈顺序不变，布局版本升级为 3。尾部按顺序：nTrajectoryState(UINT)，nReceivedCount、nLoadedCount、nPointCount、nCurrentPoint、udiReceivedSequence、udiAcceptedSequence、udiErrorId(7×UDINT)，nUploadStation(UINT)，以及 xUploadBusy、xDataReady、xTrajectoryBusy、xRunning、xDone、xError、xStopped、xMotionPermit、xConfigValid、xAxesIdle、xAxisFault、xAxesStopped(12×BOOL)。总长 148 字节，双方 Pack=1。xAxesStopped 用于停稳确认，xAxesIdle 还要求停止等异步块释放，不能混用。

## 验证边界

离线测试执行真实 C# 服务和导入器，ADS 使用替身；覆盖四轴相同数据、批次边界、应答超时、写失败、心跳停滞、只回原未就绪轴、重复操作、准备期间停止和取消后禁止继续启动。PLC 测试执行实际 ST 的收段/拼表、权限门控、旧表失效和正常停止分支；NC 调用仍需 XAE 编译及仿真/现场验证。

页面已按多种窗口尺寸实例化渲染，150% 为缩放模拟，不等同于全部真实 DPI/显卡环境验证。源代码与编译成功不代表在线 PLC 已升级。部署需两端一起更新到版本 3；操作软件不会自动下载 PLC 或发送实机轨迹。上传最大表的实际耗时、接收区容量及 2 ms 实时性需在目标控制器测量。

本次交付验证：Release 0 警告/0 错误；离线回归包含布局 82 条 C# 断言与服务/文件/批次 49 条 C# 断言。当前工作布局和仅含本次变更的提交布局各通过 20 项窗口/缩放检查。没有连接实际 PLC 发运动命令。
